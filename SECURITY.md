# Security Policy

## Reporting A Vulnerability

Please report security vulnerabilities privately by emailing the maintainer listed in `package.json`.

Include:

- Affected version or commit.
- Reproduction steps.
- Impact and expected attacker capability.
- Any relevant logs, screenshots, or proof-of-concept code.

Do not open a public issue for exploitable vulnerabilities until a fix is available.

## Supported Versions

Security fixes target the current `main` branch and the latest published desktop/CLI release.

## Disclosure

We aim to acknowledge reports within 72 hours, validate confirmed issues, and coordinate a fix before public disclosure.
